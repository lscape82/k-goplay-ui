# 샘플의 텍스트 모션을 적용한 하이마트 광고

사용자가 지정한 바탕화면 PNG를 그대로 고정하고 중앙 영역에만 글자를 합성합니다.
첨부된 에디티지 샘플의 큰 글자 축소, 순차 등장, 위로 자리 이동, 좌우 마스크 리빌을 참고했습니다.
샘플을 그대로 복제한 영상이 아니라 세로형 중앙 공간과 레드·골드 광고에 맞춘 구현입니다.

0–4초 입주·혼수·이사 / 준비 중이시라면
4–8초 올해 마지막 / 특별행사
8–12초 삼성 엘지 / 인기 가전 / 총 집합
12–16초 가격만큼은 / 기대하셔도 좋습니다
16–20초 가전 구입혜택은 / 오픈 행사점이 가장 좋습니다

문구의 따옴표와 슬래시는 강조 및 순차 등장 지시로 해석해 화면에 표시하지 않습니다.
‘준비 중 이시라면’은 ‘준비 중이시라면’으로 띄어쓰기를 정리했습니다.

1080×1920 / 30fps / 정확히 600프레임 / H.264 / 무음 / CRF14.
render.py 상단 SCENES에서 문구·시간·위치·크기·모션을 수정할 수 있습니다.

python render.py --preview --render
python verify.py

필요 패키지: Pillow, numpy, imageio-ffmpeg. 폰트: Windows NotoSansKR-VF.ttf.
