# 롯데하이마트 샘플 기준 모션 수정본

참조: 250804_LEESEEDX_D2_롯데하이마트_성서점_광고영상.mp4.
샘플에서 확인한 짧은 세로 등장, 좁은 자간의 흰색 고딕, 윤곽선에서 채움으로 전환,
강조 글자의 확대·축소와 확대된 윤곽선 잔상을 중앙 텍스트에 적용합니다.
현재 배경은 사용자가 지정한 PNG 그대로 고정합니다.

원본 영상은 1920×1080, 약20.05초,29.97fps이며 출력은 사용자 규격인1080×1920,20초,30fps입니다.
서로 다른 문구 및 고정 배경 조건 때문에 원본 영상 전체의 프레임별 복제는 아닙니다.
폰트 파일 이름은 MP4에서 확인할 수 없습니다. 설치된 한글 폰트와 원본의 ‘가격만큼은’ 윤곽을 비교해
가장 가까운 Noto Sans KR 가변폰트 weight650,tracking -0.075em을 사용합니다.
최상위 비교 결과의 이진 마스크 교집합/합집합은 약0.955(크기 정규화 후)입니다.

장면:0–4 입주·혼수·이사,4–8 특별행사,8–12 삼성 엘지,12–16 가격,16–20 구입혜택.
개별 등장 시간0.2–0.4초.정확한 값은 render.py 상단 SCENES 참조.
출력:H.264,yuv420p,CRF14,오디오 없음.

python render.py --preview --render
python verify.py

필요 패키지:Pillow,numpy,imageio-ffmpeg.
