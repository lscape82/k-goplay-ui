# 지시서 적용 신규 버전

원본 건물 배경과 고해상도 광고의 브랜드·타이틀·일정 자산을 재사용했습니다.
이전 MP4를 덮어쓰거나 완성 영상 위에 새 카피를 덧씌우지 않습니다.

## 구성

- 0–3초: 독립 GRAND OPEN 오프닝. 2.4–2.8초 상단 45% 축소.
- 3–6초: 입주·혼수·이사 단어별 마스크 리빌과 한 번의 스케일 정착.
- 6–9초: 특별행사 외곽선 복제 및 글자별 채움, 확대 퇴장.
- 9–12초: 삼성·엘지 좌우 등장, 인기 가전·총집합 하단 리빌.
- 12–15.5초: 가격 문구 강조 후 재배치, 기대 문구 좌우 채움. 중앙 크림색 전환.
- 15.5–20초: 최종 혜택 외곽선→채움, 17.2초 이후 카피 완전 고정.

브랜드와 일정은 별도 레이어. 원형 와이프와 색상 패널은 중앙 영역만 사용합니다.
배경 건물은 비율을 보존한 100→103% 확대입니다.
블러는 움직이는 순간에만 적용하는 Gaussian blur이며 시간 누적 모션 블러는 아닙니다.
정지 구간의 글자는 블러 0입니다. 임의 효과나 반복 바운스는 없습니다.

## 수정과 실행

render.py 상단 CONFIG와 COPY에서 문구·위치·크기를 수정합니다.
stage()와 frame()의 시간값으로 키프레임을 수정합니다.
프레임0–599를 n/30초에 계산하며 정확히600프레임을 인코딩합니다.

```powershell
python render.py --preview
python render.py --render
python verify.py
```

필요 패키지: Pillow, numpy, imageio-ffmpeg.
폰트: C:/Windows/Fonts/NotoSansKR-VF.ttf.
assets 안에 원본 이미지가 포함되어 재렌더링할 수 있습니다.
previews/contact_sheet.jpg는6개 장면, transition_1~6.jpg는0.1초 간격 전환 검수용입니다.
validation.json은최종 MP4의 전체디코딩·스트림 검증 결과입니다.
