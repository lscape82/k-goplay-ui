현재 20초 하이마트 광고를 참조 MP4의 키네틱 타이포그래피 리듬으로 수정해줘. 현재의 붉은 배경·실제 매장 건물·금색 브랜드 분위기를 유지하되, 중앙 카피가 장면을 이끌도록 만들어줘. 6장의 완성 포스터를 교차 페이드하는 방식으로 구현하지 말고, 단어·글자·외곽선·마스크를 분리해서 실제로 움직여줘.

먼저 기존 제작 소스와 텍스트 없는 배경을 찾아 재사용해줘. MP4의 글자는 이미 영상에 합쳐져 있으므로, 완성 MP4 위에 새 글자를 중복으로 덧씌우지 마. 편집 가능한 소스가 없으면 제공된 깨끗한 배경에서 타이포 레이어를 재구성해줘. 깨끗한 배경도 없으면 부족한 자산을 명시하고, 건물·로고를 생성형 이미지로 임의 재작성하지 마.

### 화면과 출력

- 1080×1920, 정확히 20초, 30fps, 총 600프레임. MP4/H.264, yuv420p, 무음. 프레임 번호는 0~599, 시간구간은 시작 포함·끝 제외.

### 공통 모션 규칙

- 등장 기본 길이 0.2~0.35초, 퇴장 0.15~0.25초. 등장 후 반드시 읽는 시간을 둬.
- 빠른 등장 감속은 cubic-bezier(0.16,1,0.3,1), 퇴장 가속은 cubic-bezier(0.7,0,0.84,0). 스케일 정착은 명시한 키프레임으로 한 번만 오버슈트하고 반복 바운스 금지.
- blur 수치는 1080px 출력 기준의 제안값. 등장 시 8~14px→0, 정지 시 항상 0. 단순 가우시안 블러를 쓸 경우 실제 모션 블러라고 표기하지 마. 렌더러가 지원하면 움직이는 레이어만 시간 샘플 누적으로 처리하되 정지 글자에 잔상을 남기지 마.
- 자간은 em 단위로 지정. 0.10em→0em 정도의 약한 압축만 사용. 픽셀 자간과 혼동하지 마.
- 외곽선 복제는 독립 레이어로 구현. 채움 없는 2~3px 선, 불투명도 15~25%. 본문 뒤에 배치.
- 이전 카피는 다음 카피가 읽히기 전에 완전히 제거. 전환용 복제만 예외로 하며 의미 있는 두 문장을 겹쳐 읽게 만들지 마.

- 0.0–0.2: 배경과 브랜드를 보여주며 시작. 긴 검정 페이드 금지.

2. 프레임 번호로 시간을 고정하고 글자마다 위치·마스크·외곽선·채움 상태를 제어. 무작위 효과는 쓰지 마.
3. 오프닝, 특별행사, 가격 메시지, 엔딩의 정지 프레임과 전환 중간 프레임을 확인. 텍스트 잘림·잘못된 줄바꿈·중복 카피·로고 변형이 있으면 수정.

5. 최종 MP4가 1080×1920 / 30fps / 600프레임 / 20초 / 무음인지 확인. 중간 프레임에서만 필요한 블러가 정지 구간까지 남지 않도록 검사.
